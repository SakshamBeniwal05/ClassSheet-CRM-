1. ROUTING & STATE MACHINE ARCHITECTURE
--------------------------------------------------------------------------------
CallSheet utilizes a reactive, state-driven SPA routing model managed centrally by 
Zustand in `userStore.currentPage` and rendered conditionally in `App.tsx`.

Session Gatekeeper:
- If `userData === null`:
    * If `currentPage === 'otp'`           ==> Renders <OTP />
    * If `currentPage === 'reset-password'` ==> Renders <ResetPassword />
    * Default                              ==> Renders <Login /> (Includes Login, Register, and Forgot Password views)
- If `userData !== null`:
    * If `currentPage === 'dashboard'`     ==> Renders <Dashboard />
    * If `currentPage === 'clients'`       ==> Renders <Clients />
    * If `currentPage === 'deals'`         ==> Renders <Deals />
    * If `currentPage === 'reminders'`     ==> Renders <Reminders />
    * If `currentPage === 'employees'`     ==> Renders <Organisation />
    * Default                              ==> Renders <Dashboard />

                 +----------------------+         +-----------------------+

                 +----------------------+         +-----------------------+
                                                              |
                               +------------------------------+------------------------------+
                               |                              |                              |
                               v                              v                              v
                    +--------------------+         +--------------------+         +--------------------+
                    |     TOP NAVBAR     |         |     LEFT SIDEBAR   |         |    ACTIVE CANVAS   |
                    | Org Badge, Profile,|         | Navigation links:  |         | Dynamically loads  |
                    | Session indicators |         | Dashboard, Clients,|         | component based on |
                    | Logout trigger     |         | Deals, Reminders,  |         | currentPage        |
                    +--------------------+         | Team / Employees   |         +--------------------+
                                                   +--------------------+                    |
                                                              |                              |
                                                              v                              |
                          +------------------------------------------------------------------+
                          |
                          +---> currentPage === 'dashboard'
                          |     - Renders <Dashboard />
                          |     - Queries: recent deals, metric tallies, reminders
                          |
                          +---> currentPage === 'clients'
                          |     - Renders <Clients />
                          |     - Queries: GET /api/client
                          |     - Actions: Add Client Modal, Edit Client, Delete Client
                          |
                          +---> currentPage === 'deals'
                          |     - Renders <Deals />
                          |     - Queries: GET /api/deal
                          |     - Actions: Kanban Drag & Drop (PUT /api/deal/:id),
                          |                Add Deal Modal, Deal Drawer
                          |                - Sub-tab Notes (GET/POST /api/notes)
                          |                - Sub-tab Media (Direct ImageKit upload + POST /api/media)
                          |
                          +---> currentPage === 'reminders'
                          |     - Renders <Reminders />
                          |     - Queries: GET /api/reminder
                          |     - Actions: Quick Add, Status Toggle (PUT /api/reminder/:id/status), Delete
                          |
                          +---> currentPage === 'employees'
                          |     - Renders <Organisation />
                          |     - Queries: GET /api/organisation/members
                          |     - Actions: Generate Invite Token (POST /api/organisation/invite-token),
                          |                Change Member Role (PATCH /api/organisation/members/:id/:role),
                          |                Remove Member (DELETE /api/organisation/members/:id)
                          |
                          +---> Logout Action
                                - Triggers POST /api/auth/logout
                                - Clears memory access token & HTTP-Only refresh cookie
                                - Sets userData = null, currentPage = 'dashboard'
                                - Returns to Login View
